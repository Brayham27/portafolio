PokéWall

A free web app that turns all 1,025 Pokémon into a wallpaper, arranged by color, type, size or Pokédex number

CompanyPersonal project
RoleProduct designer
Year2026
ScopeProduct definition, UX/UI, responsive design, SEO
StatusLive
Linkpokewall-omega.vercel.app
The challenge

1,025 sprites, four art styles and many screen sizes, all in the browser. It had to feel simple for a casual visitor and still give real control to someone who wants to fine tune.

My move

I defined the product around one job, designed the experience for desktop and mobile, and simplified it in rounds of review until every control earned its place.

The result

A live, bilingual app that exports wallpapers in 4K, ultrawide, MacBook and iPhone sizes, with a public counter of wallpapers created.

Context

The problem

I wanted a wallpaper with every Pokémon sorted as a color gradient. The ones I found were static images made by hand, in a single size and a single style.

PokéWall turns that image into a tool, so anyone can create their own version for their screen in a couple of minutes.

My role

PokéWall is my own project. I defined the product, designed the interface and its behavior, and directed every iteration. The code was built with AI-assisted development (Claude), which let me move from idea to a live product in days.

Design decisions
01

One job: a great wallpaper for my screen, fast

Every decision was tested against that job. The default result already looks good, so the first download can happen in seconds, and the controls are there for people who want to go further.

02

Patterns instead of settings

The first version had 33 visible controls. Through rounds of review I grouped them into six visual patterns, turned fine tuning into smart defaults and put filters in tabs. The panel went down to 13 controls without losing what the product is for.

03

Mobile as a photo editor

On phones the canvas stays in the center and every section opens as a bottom sheet with Cancel and Done, a pattern people already know from photo apps. The image shrinks above the sheet so changes are visible while you make them.

04

Direct manipulation, with a safety net

Any Pokémon can be dragged into place. Changes can be undone step by step, and if a new pattern would erase manual work, the app says so and offers to undo instead of discarding it silently.

Designed and shipped

Designed by me, built with AI-assisted development.

Responsive by design

The mobile layout is its own design, not a squeezed desktop: tool bar, bottom sheets and a format picker that shows the shape of each screen.

The output

Four sprite styles, from classic pixel art to 3D renders, exported at full resolution. Pixel styles scale in whole steps so they stay sharp on a 4K screen.

Launch details

Spanish and English, SEO and structured data so the project can be found, and a public counter of wallpapers created that lives inside the info modal.

Reflection

PokéWall started as a wallpaper for myself and became a small product. The most valuable part was not adding features but removing them: the review rounds are where the experience got good.
